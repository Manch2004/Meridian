# Meridian Bot

Простой приветственный Telegram-бот для Meridian на Node.js (Telegraf).

## Запуск

```bash
npm install
cp .env.example .env   # и вписать BOT_TOKEN, полученный от @BotFather
npm start
```

Бот отвечает приветственным сообщением на `/start`, на любое сообщение и приветствует новых участников в группах.
